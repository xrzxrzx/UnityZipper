## 3. 关键设计决策（速查，详见设计稿）

1. **引用计数只信 Addressables 原生**，封装层只簿记（HashSet<AssetHandleBase>，句柄自带 Address/Owner），不二次计数、不做"按地址一键释放"。
2. **句柄凭证语义统一**：`AssetHandle<T>.Dispose()` 是唯一释放路径（internal 构造防伪造，注入 _unbook 销号回调，幂等）；`Release(handle)` 仅转发。勿再拆出第二条释放方法。
3. **键边界（v0.2 核心修订）**：框架公共 API **只收 address/label**（Addressables 原生 key），业务键清单移出框架；解析器（IAssetKeyResolver：业务键→address）列为 M1 后演进。AssetKey 枚举/Registry 方案已废弃，勿按旧文档实现。
4. **池化路径**：母本 PrefabAsset 长期保活 + 克隆体走原生 Instantiate + ZObjectPool（组件实现 IZObjectPoolItem，OnGet/OnReturn 自管 SetActive）。销毁顺序：先清池再 PrefabAsset.Dispose。池内勿混用 Addressables.InstantiateAsync（tracked 实例须 ReleaseInstance）。
5. **异步栈**：对外全 UniTask；IAsyncStartable.StartAsync 返回类型随宏变化（本工程 UPM UniTask → UniTask；退回 vendor → Task），bootstrapper 只 await 一行不受影响。
6. **初始化**：Addressables 不显式调也能自动初始化；`ZResourceManager.InitializeAsync` 幂等（AsyncLazy），由 ResourcesBootstrapper 在 Scope 启动时 await 一次。

## 4. 本周事故与结论（重要）

- **UniTask vendor → UPM 迁移**（用户决定）：manifest 改为 git 源 `com.cysharp.unitask@2.5.11`，删除 Assets/Plugins/UniTask。→ VContainer 宏 `VCONTAINER_UNITASK_INTEGRATION` 生效（IAsyncStartable 变 UniTask 版）。
- **编译链事故**：曾出现 Cysharp/UniTask CS0246 全工程报错。根因链：① 双 Unity 实例争 Library；② PackageCache 缓存污染（immutable 警告，UniTask 文件被"意外修改"）；③ 删缓存重拉后仍不编译 → 疑 Library/Bee 增量缓存指向旧 vendor 产物。**当前状态：用户重开 Unity 后依赖恢复正常、编译通过**（具体解决动作=重开+缓存重拉，Bee 清理是否执行过待确认）。
- **遗留警告两条**（2026-09-06）：① immutable packages altered（UniTask 文件列表）——疑一次性噪音，**待重开 Unity 验证是否再现**，再现则需清整个 Library 或回滚 vendor；② UDP 56906 VS/Unity messaging——瞬时端口冲突，当前已释放，无害。
- **回滚 vendor 仍是备选方案**：UPM 与 roadmap §6「.unitypackage 分发 + 依赖 vendor」策略冲突，分发前必须决策（UPM 无法进 .unitypackage）。

## 5. 设计稿修订史（v0.1 → v0.2 关键点）

- LoadAsync 由返回裸 T 改为返回 `AssetHandle<T>`（句柄即凭证，自洽）
- asmdef 引用澄清：**四程序集**（UniTask/Unity.Addressables/Unity.ResourceManager/UniTask.Addressables），引用不传递
- IAsyncStartable 三分支签名（UPM UniTask / Unity2023 Awaitable / vendor Task）→ 本工程现为 UniTask
- AssetKey 枚举方案废弃 → 框架收原生 key（§3 决策 3）
- 簿记结构：Dictionary+List → HashSet<AssetHandleBase>（消灭 object/out 坑）
- AssetHandle 释放语义统一为 Dispose（修 res.Release vs Dispose 分叉）
- E1 对齐真实类名 ZObjectPool/IZObjectPoolItem + 释放顺序纪律
